# Tooltip Studio 1.9.0 验证记录

本次发布分别构建 Minecraft 1.20.4、1.21.1、1.21.2、1.21.3、1.21.4。每个 JAR 的游戏版本约束均为对应的精确版本。

## 自动化检查

- 共 432 项单元测试：1.20.4 为 88 项，四个新版各 86 项。
- 五个版本均通过开发客户端启动和实际 tooltip 渲染测试，包含物品作用域、资源包重载和原版预览组件。
- 四个新版验证了旧 Monumenta NBT 路径读取 custom_data、原版组件、多条件组合、默认组件、数值/字符串类型区分及缺失字段不匹配。
- 注册测试模组自己的组件并通过其 Codec 匹配，确认不限于硬编码的原版组件。
- 验证组件匹配同时控制样式和独立装饰，TooltipStyle 覆盖仍保留装饰；重载失败保留旧状态，停用资源包移除其规则。
- 验证独立动画 PNG、大写贴图路径、多段彩色文字、缩放与偏移，并检查真实截图中的装饰尺寸与动画换帧。
- 1.21.1、1.21.4 使用游戏的命令参数解析器验证全部五条转换后的旧示例命令及新组件示例命令。
- 发行检查包含 JAR 元数据、Mixin 映射、Java 字节码版本、默认贴图和图标校验值、示例资源包格式及开发测试代码未进入发行 JAR。
- 旧实例的 10 份 JSON 在回归前后校验值一致，没有被自动改写。

## 重现

使用 JDK 21：

```sh
./gradlew buildAllVersions
./gradlew -Pmc=1.21.1 :mc1.21.1:runSmoke
./gradlew -Pmc=1.21.4 -PcompatShulker :mc1.21.4:runSmoke
./gradlew -Pmc=1.20.4 -Ploader_version=0.15.11 -PsmokeRunDir=run-smoke-port :runSmoke
./gradlew -Pmc=1.20.4 -Ploader_version=0.19.5 -PcompatShulker :runSmoke
```

客户端测试需要图形环境；GitHub Actions 运行五个版本的编译、单元测试和发行打包。开发截图保存在各版本 `run-smoke/screenshots`，不随 JAR 发布。旧版测试的 Loader 0.15.11 与 0.19.5 分别覆盖最低版本及 SBT 组合；新版使用 0.16.14。
