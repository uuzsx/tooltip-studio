02

整个系统，就记住三个东西

样式
决定“框长什么样”背景、边框、分割线 → styles
装饰
额外贴上图片或彩字不替换基础外观 → decorations
规则
决定“给哪些物品用”物品 ID、tag 或 NBT → rules
教学木棍
物品自带的说明文字
区域 : 传说
结构示意：下面这行彩字是额外装饰

名字与 lore 内容来自物品本身；本模组负责外观和额外装饰。
只有名字、没有正文时不画分割线——这是正常行为。

03

把新手包解压，找到这三个文件

解压到 resourcepacks/TooltipStudio-新手包/。
启用解压后的文件夹版本，停用原 ZIP。以后就改这份。

TooltipStudio-新手包/ ├─ pack.mcmeta ← 保留模板，别动它 └─ assets/tooltipstudio/ ├─ styles/demo.json ← 改外观 ├─ decorations/demo/label.json ← 改彩字 └─ rules/demo.json ← 挑物品

用文本编辑器打开，保存为 UTF-8；别存成 .json.txt。以下路径均从 assets/tooltipstudio/ 开始。

A改彩字decorations/demo/label.json
{
  "type": "text",
  "segments": [
    {"text": "区域 : ", "color": "#AAAAAA"},
    {"text": "传说", "color": "#FF5555"}
  ],
  "anchor": "BOTTOM",
  "y": 14,
  "foreground": true
}

只先动这两个地方

text = 显示什么字
color = 用什么颜色

灰色红色

segments 把多段彩字
拼成一个装饰。
位置和大小一起调。

每段还可加
"bold": true 粗体
"italic": true 斜体

单色可用外层 text；多色用 segments。二选一，不要同时填写。

B挑物品rules/demo.json
{
  "schemaVersion": 1,
  "rules": [
    {"style":"demo",
     "items":["minecraft:stick"]}
  ],
  "decorationRules": [
    {"decorations":["demo/label"],
     "items":["minecraft:stick"]}
  ]
}

一件物品，两种规则

rules 选基础样式。
decorationRules
额外叠加装饰。

想改成钻石剑？
把代码中两处
minecraft:stick
都换成
minecraft:diamond_sword

demo 是样式名；
demo/label 是装饰名。

引用名 = 对应目录里的路径，去掉 .json。
例如 decorations/demo/label.json → 填 demo/label，不加 decorations/ 前缀。
04

服务器物品？用 NBT 来认它

进阶时再看

想按 Monumenta.Location = forest 匹配，
把需要改的规则里的 items 字段替换成下面这一项：

"nbt": {"Monumenta.Location": "forest"}

物品分类 tag

"tags": ["minecraft:planks"]

匹配“木板”分类；不带 #。

物品自己的 NBT 数据

"nbt": {"Monumenta.Location": "forest"}

路径不加 tag.，值区分大小写。

同时写 items 和 nbt = 两个条件都得满足。只想按 NBT 判断，就删掉 items。
客户端必须实际收到这项数据；样式和装饰的匹配条件要分别修改。

05

调位置、调大小、换一套皮肤

整框移动 → styles/demo.json

"offsetY": -12整框向上 12
"offsetY": 12整框向下 12
"offsetX": 12远离鼠标，左右等距

X 负值靠近鼠标；贴边时会限制移动。

只动装饰 → 装饰 JSON

"x": 6, "y": -6右移 6、上移 6
"x_scale": 1.5横向放大到 1.5 倍
"y_scale": 0.8纵向缩小到 0.8 倍

x/y 始终正右下、负左上；缩放默认 1。

TOP_LEFT 左上角BOTTOM 底部中间SEPARATOR_CENTER 分割线中心

anchor 决定贴在哪里；没有分割线时，分割线锚点上的装饰会隐藏。

C · 想自己画皮肤？最后再动 styles/demo.json

背景＋边框＋分割线＝同一张 PNG

模板先沿用内置默认图。换自己的 PNG 时，改 texture 路径和实际宽高；
u / v / width / height 告诉模组“从图上哪一块取图”。

边框四边固定；分割线两端固定、只拉伸中间。
独立图片装饰可以使用自己的 PNG，不必跟基础样式放一张图里。

06

保存 → 重载 → 再悬停

跟本图改资源包

F3 + T

改 config/tooltipstudio/ 本地配置

/tooltipstudio reload
① 包启用了？别改了没启用的那份。
② 物品匹配了？两类规则分别检查。
③ 路径对了？引用不带 .json。
④ JSON 合法？英文引号，别多逗号。

重载失败会保留旧效果，先看聊天提示和日志。
查样式：/tooltipstudio list　查装饰：/tooltipstudio decorations
同路径资源包 JSON 会覆盖本地 JSON；新手先选一种方式改，别两头找文件。
